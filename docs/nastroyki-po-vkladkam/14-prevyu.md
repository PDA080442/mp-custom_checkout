# Вкладка «Превью»

Раздел **`preview`** по умолчанию может быть **пустым**. Превью в админке включается **точечно** в настройках шагов:

| Где | Параметр |
|-----|----------|
| Шаг 1 | `step_1.admin_preview.enabled` |
| Шаг 2 | `step_2.admin_preview.enabled` |
| Шаг 3 | внутри `copy` → `admin_preview.enabled` (в структуре по умолчанию) |
| Общие | `general.admin_branding.preview_enabled` — превью **бренда** шапки экрана настроек |

---

## Что такое «превью» для менеджера

Это **черновой просмотр** того, как может выглядеть блок на витрине или в настройках, **без** полного прохождения checkout. Удобно для проверки текстов после правок.

---

## Если вкладка «Превью» пустая

Включайте превью на **соответствующих шагах** (см. таблицу выше). Отдельная вкладка может быть зарезервирована под будущий **единый** предпросмотр.

---

## Связь с feature flag

В **Служебное** флаг `admin_live_preview` управляет **живым превью** в админке (если реализовано в вашей сборке).
