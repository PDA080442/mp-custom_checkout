# Вкладка «Шаг 3»

**Шаг 3** обычно объединяет **выбор даты** получения/доставки и блок **условий** (календарь, пояснения по сценарию, чекбокс согласия). Настройки завязаны на **три сценария**: самовывоз, доставка по городу, доставка в другой город.

---

## Сроки: минимум и максимум по дням

### `min_lead_time_days`

Сколько **полных дней вперёд** нельзя выбрать «на завтра», если нужна подготовка заказа. Задаётся **отдельно для каждого сценария**.

**Пример:** для самовывоза стоит `1` — значит первая доступная дата не «сегодня», а с учётом одного дня подготовки (логика может уточняться настройками календаря и часового пояса сайта).

### `max_days_ahead`

Как далеко в будущее можно открыть календарь (в днях от «сегодня»).

**Пример:** `14` для самовывоза — максимум две недели вперёд.

---

## Календарь: стиль (`calendar_style`)

- `density` — насколько плотно расположены ячейки (`comfortable` и т.д.).
- `day_shape` — форма ячейки дня, например `rounded` (скругление).
- `highlight_style` — как подсвечивается выбранный день (`accent` — акцентный цвет темы).
- `show_weekend_tint` — слегка выделять субботу/воскресенье.

---

## Какие дни недели разрешены (`weekday_rules`)

Для каждого сценария — **список номеров дней**: обычно `1` = понедельник … `7` = воскресенье (уточните по подсказке в админке, если в вашей версии иначе).

**Пример:** самовывоз `1,2,3,4,5,6` — без воскресенья; доставка в другой город только `1,3,5` — по понедельникам, средам и пятницам.

---

## Праздники и закрытые дни

- `holiday_dates` — даты, которые **всегда недоступны** (часто ввод списком через запятую в одном поле, формат уточняйте: обычно `YYYY-MM-DD`).
- `closed_dates` — дополнительные закрытые дни (например, инвентаризация).

**Пример:** `2026-01-01, 2026-01-07` — новогодние выходные недоступны для выбора.

---

## Тексты шага (`copy`)

- `title` — заголовок экрана. Пример: *«Выберите дату получения»*.
- `helper_by_scenario` — разные подсказки под каждый сценарий (самовывоз / доставка по городу / в другой город).
- `errors` — сообщения об ошибках:
  - `invalid_date` — дата не попала в доступные.
  - `empty_date` — дату не выбрали.
  - `conditions_unconfirmed` — не отметили согласие с условиями.

**Пример формулировки `invalid_date`:** *«Эта дата недоступна. Выберите другую.»*

---

## Условия и юридические блоки (`conditions_copy`)

Здесь задаются **вводные тексты** и блоки про офис/доставку в зависимости от сценария.

### Общие части

- `intro_by_scenario` — короткое вступление **по сценарию** (можно оставить пустым, если всё в других блоках).
- `secondary_notes` — до трёх дополнительных примечаний (массив строк).

### Блок для доставки по Красноярску (`krasnoyarsk_delivery`)

- `title`, `body` — заголовок и основной текст условий.
- `delivery_within_day` — фраза про доставку в течение дня в выбранную дату.

### Блок для другого города (`other_city_delivery`)

- `logistics_note` — про отправку транспортной компанией после сборки.

### Блок самовывоза (`pickup`)

- `office_block_title` — например *«Офис и график работы»*.
- `office_address` — адрес выдачи **текстом** для покупателя.
- `office_description` — как происходит выдача.
- `office_hours_plain` — расписание одним текстом (несколько строк).
- `office_hours` — расписание **списком** интервалов (если используется вёрсткой).
- `convenience_helper` — уточнение «можно приехать в удобное время…».
- `critical_notice` — важное предупреждение крупным текстом (если нужно).
- `show_multi_office_slot` — показывать ли место под **несколько точек** (если подключат позже).

---

## Связь с шагом 2

Сценарий выбран на **шаге 2** — на шаге 3 автоматически подставляются **соответствующие** минимальные сроки, дни недели и тексты. Если «прыгают» даты — смотрите сначала `weekday_rules` и `holiday_dates`, потом сценарий на шаге 2.
