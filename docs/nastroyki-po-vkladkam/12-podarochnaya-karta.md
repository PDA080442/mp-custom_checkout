# Вкладка «Подарочная карта»

Раздел **`gift_card`** по умолчанию может быть **пустым**. Рабочие **тексты и блоки** для подарочной карты обычно настраиваются на **шаге 4**:

- группа **`gift_card_block`** — заголовки, плейсхолдер, кнопка «Применить», сообщения;
- в **`labels`** (глобальные тексты) есть дублирующие ключи для подарочной карты;
- в **глобальных текстах** (`DefaultLabelsRegistry`) — варианты для кнопок и сообщений.

---

## Интеграция с плагином подарочных карт

На стороне WooCommerce часто используется **PW Gift Cards** или аналог. Кастомный checkout:

- показывает поле ввода кода;
- передаёт данные в **корзину/сессию** через AJAX по правилам плагина.

Если подарочная карта **не применяется**, проверьте:

1. Активен ли плагин подарочных карт.  
2. Совпадают ли **сообщения об ошибках** с реальной причиной (см. [15-logi.md](15-logi.md)).

## Если вкладка «Подарочная карта» пустая

Ориентируйтесь на **Шаг 4**. Пустая вкладка — резерв под отдельные настройки интеграции в будущих версиях.
