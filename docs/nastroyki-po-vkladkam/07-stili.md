# Вкладка «Стили»

Раздел **`styles`** в базе может быть **пустым по умолчанию**. Глобальное визуальное оформление checkout часто задаётся через **дизайн-токены** и настройки **внешнего вида по шагам** (карточки, отступы, календарь).

---

## Где на самом деле настраиваются «стили»

1. **Дизайн-токены** — цвета, шрифты, скругления, тени. В коде плагина есть набор по умолчанию (`color_text`, `color_accent`, `radius_md` и т.д.). Отдельная вкладка в админке с названием «Дизайн-токены» может **не выводиться** — токены хранятся в общих настройках и могут дополняться при сохранении.

2. **Шаг 1** — плотность карточек товара, сводка, адаптив (`style_controls`, `responsive`).

3. **Шаг 2** — плотность карточек выбора сценария (`responsive.card_density`).

4. **Шаг 3** — стиль календаря (`calendar_style`).

5. **Шаг 4** — сетки форм, стили ошибок, стили блоков скидок и оплаты.

---

## Типичные сценарии

| Задача | Куда смотреть |
|--------|----------------|
| Поменять цвет акцента на всём checkout | Дизайн-токены / CSS темы (часто через разработчика или дочернюю тему) |
| Сделать карточки товара компактнее | Шаг 1 → `style_controls`, `responsive` |
| Изменить скругление дней в календаре | Шаг 3 → `calendar_style.day_shape` |

---

## Если вкладка «Стили» пустая

Не паникуйте: заполните то, что доступно в **шагах 1–4** и в **общих** настройках. Пустая вкладка означает, что в этой сборке **отдельного массива полей** для `styles` ещё не завели — функциональность вынесена по шагам.
