# Документация настроек MP Custom Checkout

Здесь собраны **пояснения к каждой вкладке** экрана **MP Checkout** в админке WordPress (`/wp-admin/` → пункт меню **MP Checkout**).

## Как пользоваться

1. Откройте **MP Checkout** в левом меню админки.
2. Переключайте **вкладки** сверху или сбоку (можно выбрать «Верхняя навигация» / «Боковая навигация»).
3. После изменений нажмите **«Сохранить настройки»** внизу страницы (кроме вкладки **Логи** — там свои кнопки).
4. Используйте **поиск** и фильтры («тексты», «поля», «стили» и т.д.), чтобы быстро найти нужный параметр.

## Что важно понимать

- Плагин настраивает **кастомное оформление заказа** (многошаговый checkout). Корзина WooCommerce остаётся общей: этот плагин **показывает товары из корзины** на шагах и ведёт к оплате.
- У каждого поля в форме в админке обычно есть **серый код пути** (например `step_1.labels.title`) — это внутреннее имя настройки; для работы магазина достаточно понимать **человеческие подписи** и **что меняет параметр**.
- Параметры с пометкой **риска** (красная подсветка) могут сломать ссылки или логику — меняйте их осознанно и проверяйте сайт после сохранения.

## Дополнительно: что не отдельной вкладкой

Часть данных хранится в базе и может **дополнительно** выводиться на вкладке **«Служебное»** (блоки вроде *Feature flags* и *Step Registry*) — это описано в [08-sluzhebnoe.md](08-sluzhebnoe.md).

Глобальные тексты (`labels`) и дизайн-токены (`design_tokens`) по умолчанию подставляются из кода плагина; отдельных вкладок «Тексты» и «Дизайн-токены» в интерфейсе может не быть — при необходимости их можно расширять через сохранённые настройки (если они появились в вашей версии).
