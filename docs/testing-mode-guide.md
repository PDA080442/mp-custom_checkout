# Checkout Testing Mode Guide

## Purpose
Testing mode allows QA to validate payment and runtime states safely without affecting production behavior assumptions.

## How to Enable
1. Open `MP Checkout -> Служебное`.
2. Locate `checkout_testing_mode`.
3. Turn it on only in staging / controlled QA window.
4. Save settings and refresh checkout.

## What to Validate
- Sandbox scenarios in admin preview.
- Payment states: `loading`, `success`, `error`.
- Validation and recovery behavior on step transitions.
- Logs generated by test scenarios are visible and understandable.

## Safety Rules
- Do not leave testing mode enabled after QA.
- Re-check health summary before disabling.
- Export logs before cleanup.

## Disable Procedure
1. Set `checkout_testing_mode` to off.
2. Re-run short smoke checks.
3. Confirm no test-specific warnings remain in logs.
